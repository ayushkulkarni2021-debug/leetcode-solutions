## Problem: Reverse Linked List (Easy)

**Link:** https://leetcode.com/problems/reverse-linked-list/

### Approach
Iteratively reverse each next pointer using previous, current, and next pointers.

### Complexity
- Time: O(n)
- Space: O(1)

### Notes
Typical: 1→2→3 → 3→2→1. Edge: a single node → unchanged.
